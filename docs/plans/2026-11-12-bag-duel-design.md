# 《行囊决斗》设计文档

日期：2026-11-12 · 引擎：Godot 4.7.2（GL Compatibility）· 平台：Windows 键鼠 · 分辨率：1280×720

## 概述

2D 背包构筑自动战斗游戏。商店购买装备 → 拖入 7×6 背包（右下角 2×2 不可用）→ 位置联动组成构筑 → 与离线对手自动战斗。3 条命，5 胜通关。全部 UI 与图标用程序绘制（ColorRect/自定义 `_draw` + 中文单字图标），零外部资源。

## 架构

单场景 `main.tscn`（根 Control + `main.gd` 屏幕管理器），界面全部代码构建。屏幕：主菜单 / 商店（含背包整理）/ 战斗 / 结算覆盖层。

| 文件 | 职责 |
|---|---|
| `scripts/item_def.gd` | 装备静态数据表（名称、占格、价格、颜色、数值、联动描述） |
| `scripts/item_instance.gd` | 装备实例（uid、格坐标、旋转态） |
| `scripts/bag_grid.gd` | 通用格子容器：放置校验、越界/重叠/禁用格、自动找空位 |
| `scripts/build_stats.gd` | 由背包内容计算战斗数值与联动关系（边相邻判定） |
| `scripts/opponents.gd` | 7 套离线对手构筑（快攻/重剑/护盾/弓手/毒/均衡/混合） |
| `scripts/combatant.gd` | 战斗单位：生命/护盾/武器冷却/治疗触发/中毒计时 |
| `scripts/item_view.gd` | 装备视觉（色块+描边+图标字），兼作战斗冷却图标 |
| `scripts/grid_view.gd` | 格子绘制 + 放置预览（绿/红幽灵格） |
| `scripts/shop_screen.gd` | 商店、拖拽/旋转/出售、悬停提示、联动高亮、对手预览 |
| `scripts/battle_screen.gd` | 战斗模拟驱动、双方状态面板、事件日志、1×/2× 速度、暂停 |
| `scripts/main.gd` | 运行状态（金币/命/胜场/轮次）、屏幕切换、结算 |

## 装备数值

| 装备 | 占格 | 价格 | 效果 |
|---|---|---|---|
| 匕首 | 1×2 | 3 | 4 伤害 / 1.0s |
| 重剑 | 1×3 | 6 | 10 伤害 / 2.4s |
| 盾牌 | 2×2 | 5 | 开场护盾 15 |
| 弓 | 2×3 | 7 | 6 伤害 / 2.0s（远程） |
| 箭袋 | 1×2 | 3 | 与弓边相邻：弓间隔 ×0.8 |
| 治疗瓶 | 1×1 | 4 | 生命首次 <50% 回复 20 |
| 毒瓶 | 1×1 | 4 | 开场使对手中毒：2/s × 5s（穿盾） |
| 磨刀石 | 1×1 | 3 | 与武器边相邻：该武器伤害 +2 |

联动均为边相邻（斜角不算），同一来源对同一目标只生效一次，不同来源可叠加。移动/旋转/出售后立即重算。

## 经济

初始 15 金币；战后 +8；刷新商店 1 金币；出售返还 ⌊购买价/2⌋。每轮商店 5 件，首轮保证至少一件买得起的武器。

## 战斗

双方各 100 生命。武器按间隔攻击（护盾先吸收）；毒伤每秒一次、持续 5 秒、不同来源独立计时、穿盾；治疗瓶在生命首次低于一半时全部未用瓶各触发一次。同一帧双方死亡 → 平局；60 秒未分胜负 → 平局。失败或平局扣 1 命；5 胜通关；命尽失败。

## 交互

- 拖拽移动装备；R 键或滚轮旋转 90°；绿/红占格预览；非法放置回到拖拽前位置。
- 点击商店卡片购买（自动进暂存区）；拖到「出售区」出售。
- 悬停显示价格/占格/数值/联动条件；悬停时高亮当前生效的联动对象（金框）。
- 战斗界面：双方生命/护盾条、装备冷却图标、事件日志、1×/2× 速度、Esc 暂停。
- 主菜单、操作提示、暂停菜单、单场结算与通关/失败结算页。
